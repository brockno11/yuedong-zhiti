# 产品需求文档（PRD）规范

## PRD 结构

### 1. 执行摘要
```markdown
## 执行摘要

### 产品名称
体测星图 - 中学生体质健康测试 AI 分析平台

### 产品定位
面向中学体育教学的智能分析平台，通过 AI 技术将体测数据转化为可视化报告和个性化训练建议。

### 目标用户
- **主要用户**：中学体育教师
- **次要用户**：中学生
- **利益相关者**：学校管理者、家长

### 核心价值
1. **数据可视化**：将复杂体测数据转化为直观图表
2. **智能分析**：AI 生成个性化训练建议
3. **教学辅助**：帮助教师精准教学
4. **健康管理**：帮助学生科学锻炼

### 成功指标
- 教师使用率 > 80%
- 学生查看报告率 > 70%
- 训练计划完成率 > 50%
- 用户满意度 > 4.0/5.0
```

### 3. 功能规格
```markdown
## 功能规格

### 功能优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 班级管理 | 核心功能 |
| P0 | 数据录入 | 核心功能 |
| P0 | 体测报告 | 核心功能 |
| P1 | AI 分析 | 核心差异化 |
| P1 | 训练计划 | 核心价值 |
| P2 | 数据导出 | 辅助功能 |
| P2 | 通知提醒 | 增强体验 |

### 详细功能说明

#### 3.1 班级管理
**功能描述**：
管理班级信息和学生名单

**数据模型**：
```typescript
interface Class {
  id: string
  name: string           // "初二(3)班"
  grade: string          // "初二"
  teacherId: string
  studentCount: number
  createdAt: Date
  updatedAt: Date
}
```

**API 接口**：
- `GET /api/classes` - 获取班级列表
- `POST /api/classes` - 创建班级
- `PUT /api/classes/:id` - 更新班级
- `DELETE /api/classes/:id` - 删除班级

**UI 界面**：
- 班级列表页：卡片式展示
- 班级详情页：学生列表
- 创建/编辑表单：Dialog 弹窗

#### 3.2 数据录入
**功能描述**：
批量导入体测数据

**支持格式**：
- Excel (.xlsx)
- CSV (.csv)

**数据字段**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 姓名 | string | 是 | 学生姓名 |
| 性别 | enum | 是 | male/female |
| 身高 | number | 否 | 单位：cm |
| 体重 | number | 否 | 单位：kg |
| 50米跑 | number | 否 | 单位：秒 |
| 立定跳远 | number | 否 | 单位：cm |
| 肺活量 | number | 否 | 单位：ml |
| 坐位体前屈 | number | 否 | 单位：cm |

**验证规则**：
- 必填字段检查
- 数据类型检查
- 合理范围检查
- 重复数据检查

#### 3.3 体测报告
**功能描述**：
展示学生体测报告

**报告内容**：
1. 综合评分和等级
2. 各项指标得分
3. 雷达图
4. 成绩趋势
5. AI 分析（待审核）
6. 训练建议（待审核）

**等级标准**：
| 等级 | 分数范围 | 颜色 |
|------|---------|------|
| 优秀 | 90-100 | 绿色 |
| 良好 | 80-89 | 蓝色 |
| 及格 | 60-79 | 橙色 |
| 待提升 | < 60 | 红色 |

#### 3.4 AI 分析
**功能描述**：
AI 生成个性化分析和建议

**分析内容**：
1. 体质画像（优势、待提升）
2. 趋势分析（进步/退步）
3. 训练建议（具体动作、频率）
4. 注意事项（安全提醒）

**审核流程**：
1. AI 生成草稿
2. 教师审核
3. 修改/批准
4. 学生可见

**安全约束**：
- 不生成医学诊断
- 不使用负面标签
- 强调"提升空间"而非"差"
- 建议需符合学生年龄
```

### 4. 技术规格
```markdown
## 技术规格

### 技术架构
```
┌─────────────────────────────────────┐
│           前端 (Next.js)            │
├─────────────────────────────────────┤
│          API Layer (tRPC)           │
├─────────────────────────────────────┤
│         Database (PostgreSQL)       │
├─────────────────────────────────────┤
│           AI Service (API)          │
└─────────────────────────────────────┘
```

### 性能要求
| 指标 | 目标 | 说明 |
|------|------|------|
| 首屏加载 | < 2s | 移动端 4G |
| API 响应 | < 500ms | P95 |
| 图表渲染 | < 1s | 复杂图表 |
| 数据导入 | < 30s | 1000 条记录 |

### 安全要求
- HTTPS 强制
- JWT 认证
- 数据脱敏
- 权限控制
- 操作日志

### 兼容性要求
- **浏览器**：Chrome 90+, Safari 14+, Firefox 88+
- **移动端**：iOS 14+, Android 10+
- **屏幕**：320px - 2560px
```
