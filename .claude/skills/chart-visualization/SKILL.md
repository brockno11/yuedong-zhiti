# 体测星图图表可视化规范

## 图表选型指南

### 个人体质雷达图
- **用途**：展示学生各项体测指标的综合情况
- **图表类型**：Radar Chart
- **数据字段**：
  - 维度：速度、力量、耐力、柔韧性、协调性
  - 数值：各项得分（0-100）
  - 对比：班级平均值、个人历史最高
- **交互**：
  - 悬停显示具体分数
  - 点击维度跳转到详情
  - 切换对比对象
- **空状态**：暂无体测数据，请先完成体测
- **异常值**：超过 2 个标准差的数据标红提示

### 单项成绩趋势折线图
- **用途**：展示学生某项体测成绩的变化趋势
- **图表类型**：Line Chart
- **数据字段**：
  - X 轴：测试时间（学期/月份）
  - Y 轴：成绩数值
  - 多线：个人成绩、班级平均、年级平均
- **交互**：
  - 悬停显示具体数值
  - 缩放查看详细时间点
  - 切换不同体测项目
- **空状态**：仅有一次测试数据，暂无趋势
- **异常值**：成绩下降超过 20% 标橙提示

### 班级薄弱项排行柱状图
- **用途**：展示班级在各体测项目上的表现
- **图表类型**：Bar Chart（横向）
- **数据字段**：
  - Y 轴：体测项目名称
  - X 轴：及格率/优秀率
  - 排序：按及格率升序（最弱的在最上面）
- **交互**：
  - 悬停显示详细数据
  - 点击项目查看学生明细
  - 切换及格率/优秀率视图
- **空状态**：暂无班级数据
- **异常值**：及格率低于 50% 标红

### 等级分布饼图/环形图
- **用途**：展示班级学生体测等级分布
- **图表类型**：Pie Chart / Donut Chart
- **数据字段**：
  - 分类：优秀、良好、及格、待提升
  - 数值：人数占比
  - 颜色：绿、蓝、橙、红
- **交互**：
  - 悬停显示人数和百分比
  - 点击分类查看学生名单
- **空状态**：暂无等级数据
- **异常值**：待提升比例超过 30% 标红警告

### 训练打卡趋势图
- **用途**：展示学生训练打卡情况
- **图表类型**：Area Chart
- **数据字段**：
  - X 轴：日期
  - Y 轴：打卡次数/时长
  - 面积：累计打卡量
- **交互**：
  - 悬停显示当日详情
  - 切换日/周/月视图
- **空状态**：暂无打卡记录
- **异常值**：连续 7 天未打卡标橙提醒

### 教师端数据概览卡
- **用途**：教师端首页核心指标展示
- **图表类型**：Stat Card + Mini Chart
- **数据字段**：
  - 主指标：学生总数、平均分、及格率、优秀率
  - 趋势：环比变化（↑↓）
  - 迷你图：最近 7 天趋势
- **交互**：
  - 点击卡片跳转详情
  - 悬停显示计算说明
- **空状态**：暂无数据，请先导入体测数据
- **异常值**：指标异常波动标红

## 图表样式规范

### 颜色系统
```css
/* 图表主色 */
--chart-primary: oklch(0.6 0.2 250);    /* 蓝色 - 主数据 */
--chart-secondary: oklch(0.7 0.15 150);  /* 绿色 - 对比数据 */
--chart-accent: oklch(0.7 0.2 80);       /* 橙色 - 警示 */
--chart-danger: oklch(0.6 0.25 25);      /* 红色 - 危险 */

/* 等级颜色 */
--level-excellent: oklch(0.7 0.2 145);   /* 优秀 - 深绿 */
--level-good: oklch(0.7 0.15 220);       /* 良好 - 蓝色 */
--level-pass: oklch(0.7 0.15 80);        /* 及格 - 橙色 */
--level-improve: oklch(0.6 0.2 25);      /* 待提升 - 红色 */
```

### 字体规范
- 图表标题：14px，粗体
- 坐标轴标签：12px，常规
- 数据标签：12px，常规
- 提示框：13px，常规

### 响应式适配
- **手机**（< 640px）：图表宽度 100%，隐藏部分标签
- **平板**（640-1024px）：图表宽度 50%，显示所有标签
- **桌面**（> 1024px）：图表宽度 33%，完整交互
