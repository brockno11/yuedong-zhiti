## 技术决策记录

### 为什么选 Next.js 14？
Server Components 默认渲染，首屏快；App Router 文件系统路由，结构清晰；API Routes 一体化，无需额外后端。

### 为什么选 SQLite？
演示环境零配置，单文件数据库，Prisma ORM 提供类型安全访问。生产环境可迁移到 PostgreSQL。

### 为什么选 DeepSeek？
国产大模型，中文理解准确，响应速度快（2-3秒），符合政策导向。

### 为什么用 Trae CN？
内置 AI 代码助手，支持中文交互，降低 Web 开发门槛，让体育教师也能自主开发。

### 为什么 localStorage + SQLite 双存储？
登录态用 localStorage（快速读取），业务数据用 SQLite（持久化 + 关联查询）。localStorage 还承担 AI 缓存和引导草稿。
