# 跃动智体 — 产品需求文档 (PRD)

> 面向中学生体质健康提升的 AI 智能评价与个性化运动指导系统  
> 版本：MVP 0.1.0 | 日期：2025-05

---

## 1. 执行摘要

### 产品名称
**跃动智体**——中学生体质健康 AI 智能评价与个性化运动指导系统

### 产品定位
面向中学体育教学的智能信息系统。采用移动端优先的响应式网站设计，帮助学生记录身体基础信息、体测数据、运动表现和运动后体感；通过数据可视化展示身体情况和体测变化；通过 AI 生成体质画像、薄弱项分析和个性化训练计划；教师端可查看班级体测概况、学生画像、AI 班级报告，并对 AI 建议进行审核后使用。

### 目标用户
- **主要用户**：中学体育教师
- **次要用户**：中学生（12-16岁）

### 核心价值
1. **数据可视化**：将复杂体测数据转化为直观图表（雷达图、趋势图、分布图）
2. **智能分析**：AI 生成个性化训练建议（体质画像 + 薄弱项分析 + 训练计划）
3. **教学辅助**：帮助教师精准了解班级体质状况，分层指导学生
4. **AI 辅助 · 教师主导**：AI 生成建议，教师审核把关，确保内容安全合适

### 成功指标（MVP）
- 学生能完成一次完整的体测记录流程
- Dashboard 能展示可视化数据（雷达图、趋势图）
- AI 指导页能展示体质画像、薄弱项、训练计划
- 教师端能显示班级总览、学生列表、AI 报告、审核中心
- 所有 AI 内容标注「AI生成，需经体育教师审核后使用」
- 移动端布局正常，底部导航可用

## 4. 技术规格

### 技术架构

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | Next.js 14 | App Router, Server Components |
| 语言 | TypeScript | 严格模式 |
| UI | shadcn/ui + Tailwind CSS | CSS variables 主题系统 |
| 图表 | Recharts | 雷达图、折线图、柱状图、环形图 |
| 表单 | react-hook-form + zod | 类型安全表单验证 |
| AI | Mock 数据 + DeepSeek API 预留 | 环境变量控制切换 |
| 图标 | lucide-react | 开源图标库 |

### 性能要求

| 指标 | 目标 |
|------|------|
| 首屏加载 | < 2s |
| 页面切换 | 300ms 动画 |
| 图表渲染 | < 1s |
| 触控响应 | < 100ms |

### 安全约束

- **不做医学诊断**：所有AI输出仅涉及体育锻炼参考
- **不贴负面标签**：使用「有提升空间」替代「差」「不及格」
- **不暴露隐私**：Mock 数据使用 S001-S020 匿名标识
- **教师审核**：所有 AI 内容需审核后才推送给学生
- **API Key 保护**：API Key 仅存储在服务端环境变量
