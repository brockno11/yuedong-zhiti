# 跃动智体 — 比赛演示脚本（6-8 分钟）

> 适用于 2026 年教师人工智能应用案例征集活动录制或现场演示。

## 准备（演示前）

```bash
npm install && npx prisma db push && npm run db:seed && npm run build && npm run dev
```
浏览器打开 http://localhost:3000，关闭其他标签页，全屏模式。

---

## 0:00-0:30 项目背景（30 秒）

> "跃动智体是一个面向中学生体质健康提升的 AI 智能评价与个性化运动指导系统。
> 当前演示场景以高二（1）班为例，包含 20 名匿名学生和 1 位体育教师。
> 系统覆盖'数据采集→AI分析→教师审核→学生查看'全闭环流程。"

---

## 0:30-1:30 学生登录与首页（1 分钟）

1. 打开 `/` — 展示登录页
   > "学生和教师通过统一入口登录，支持角色切换和账号下拉选择。"
2. 选择"我是学生" → 下拉选 S001 → 输入 `demo123` → 登录
3. 自动进入 `/dashboard` — 展示首页
   > "首页回答'我今天要做什么'。顶部动态问候，核心 CTA '开始记录'。
   > 状态简卡展示评分、BMI、数据完整度。
   > 最近记录显示记录时间、体测批次、记录类型和项目成绩。"
4. 指出完整度信息
   > "已录 6/6 项表示该学生完成了全部体测项目。"

---

## 1:30-2:30 记录体测数据（1 分钟）

1. 点击"退出登录" → 选 S018 登录（部分数据学生）
2. 首页显示"已录项目均分"（非综合评分）
   > "S018 只录入了 2 个项目，系统不会把局部数据包装成完整体质评价。"
3. 点击"开始记录" → `/record`
4. 展示 Step 0：批次选择
   > "第一步选择体测批次。默认选中当前活跃批次，支持日常训练记录。"
5. 选"2025春季学期首测" → 下一步
6. 展示项目列表
   > "项目列表根据学生性别自动过滤——男生不显示仰卧起坐和 800 米跑。"
7. 选"肺活量" → 下一步 → 输入成绩 → 体感反馈 → 完成
   > "逐项体感采集是本系统的创新点——每项运动后记录疲劳程度、恢复感觉和肌肉酸痛。"
   > 注：800m/1000m 跑步成绩以「M:SS」分秒格式显示（如 3:50），而非原始秒数。

---

## 2:30-3:30 画像页（1 分钟）

1. 点击"查看体质画像" → `/portrait`
2. 展示 amber 提示条
   > "画像页顶部显示数据完整度提示：'当前画像基于已录入的 3 个项目生成，部分维度暂不评价'。"
3. 展示雷达图
   > "雷达图只显示有数据的维度，缺失维度标注'暂无数据'，不会用 0 分填充。"
4. 指出"已记录项目平均分"标签
   > "数据不完整时不显示'综合评分'，改为'已记录项目平均分'。"

---

## 3:30-5:00 AI 报告（1.5 分钟）

1. 切换到 `/ai-guide`
   > "进入 AI 指导页不会自动消耗 token，需要用户主动点击生成。"
2. 点击"生成AI报告" → 等待生成
   > "AI 正在基于已录入数据进行分析——可以看进度条。"
3. 展示报告
   > "报告包含：首屏摘要、数据完整度、生成依据、本周训练计划、已录项目分析、待补充项目。"
4. 指出"局部体质分析"标签
   > "数据完整度不足 70% 时标注'局部体质分析'——不推断未录入项目。"
5. 展示训练计划
   > "训练计划在核心位置，包含具体动作、频率、时长、注意事项。"
6. 滚动到教师审核状态
   > "所有 AI 内容标注'需经体育教师审核授权后实施'。"

---

## 5:00-6:00 教师端（1 分钟）

1. 退出 → 选"我是教师" → 张老师 → 登录
2. `/teacher` → 展示班级总览
   > "教师端顶部有体测批次筛选器，所有统计数据按批次变化。"
3. 今日教学建议
   > "基于实际数据生成教学建议，包含人数概况、薄弱项、重点关注学生。"
4. 学生列表
   > "每个学生标注'完整录入''部分录入'或'未录入'状态。"

---

## 6:00-7:00 教师审核（1 分钟）

1. 进入 `/teacher/review` → 审核中心
   > "审核中心显示待审核的 AI 报告，教师可'通过''修改后通过'或'退回'。"
2. 选择一条学生报告 → 点击"通过"
   > "审核结果实时同步到学生端。"
3. 切回学生端
   > "学生端 AI 指导页可以看到审核状态变化。"

---

## 7:00-7:30 总结（30 秒）

> "跃动智体的核心价值：对学生，可视化理解体质、获得个性化训练指导；
> 对教师，快速掌握班级全貌、获得分层教学建议；
> 对学校，数字化体测管理、AI 辅助教学决策。
> 系统坚持'AI 辅助·教师主导'理念，所有 AI 建议需经教师审核后使用。
> 谢谢。"

---

## 备用演示路径

- 展示 S020（无记录学生）→ AI 指导页显示"暂无可分析数据"
- 展示 S001 完整数据 → 画像页显示"综合评分"和完整雷达图
- 展示历史记录 `/records` → 筛选标签切换
