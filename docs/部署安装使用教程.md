## 一、项目简介

**跃动智体**是一个面向中学体育教学场景的 AI 智能信息系统，核心功能包括：

- 📊 **体质数据可视化**：雷达图、趋势图、等级分布图
- 🤖 **AI 智能分析**：全维度体质画像、单项深度分析、个性化训练建议
- 👨‍🏫 **教师审核闭环**：AI 生成 → 教师审核 → 学生查看
- 📱 **移动端优先**：适配手机与桌面端

**技术栈**：Next.js 14 + TypeScript + Tailwind CSS + shadcn/ui + Prisma + SQLite + DeepSeek AI

## 二、环境准备

### 2.1 必装软件

| 软件 | 最低版本 | 说明 | 下载地址 |
|------|---------|------|---------|
| **Node.js** | 18.0+ | JavaScript 运行时 | https://nodejs.org/ |
| **npm** | 8.0+ | 随 Node.js 自动安装 | — |
| **Git** | 2.0+ | 版本控制工具 | https://git-scm.com/ |

### 2.2 检查环境是否就绪

打开终端（Windows 用户打开 **PowerShell** 或 **命令提示符**），依次输入以下命令：

```bash
node --version
```

预期输出（版本号 ≥ 18 即可）：
```
v18.20.4
```

```bash
npm --version
```

预期输出（版本号 ≥ 8 即可）：
```
10.7.0
```

```bash
git --version
```

预期输出：
```
git version 2.45.0
```

> ⚠️ **如果提示"命令未找到"**，说明对应软件未安装或未加入系统环境变量。请先安装后再继续。

### 2.3 Node.js 安装指南（如未安装）

#### Windows 用户

1. 访问 https://nodejs.org/
2. 下载 **LTS（长期支持版）** 安装包（.msi 格式）
3. 双击运行安装程序，全程点击 **Next** 即可（默认选项即可）
4. 安装完成后**重新打开** PowerShell，再次运行 `node --version` 验证

#### macOS 用户

1. 访问 https://nodejs.org/ 下载 .pkg 安装包
2. 双击运行，按提示完成安装
3. 或使用 Homebrew：`brew install node`

#### Linux 用户

```bash
# Ubuntu / Debian
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证
node --version
npm --version
```

## 四、安装依赖

在项目根目录下执行：

```bash
npm install
```

**预期输出**（末尾类似）：

> ```bash

> ```

## 五、初始化数据库

项目使用 SQLite 作为本地数据库，无需安装额外数据库软件。依次执行以下三条命令：

### 第一步：生成 Prisma Client

```bash
npm run db:generate
```

预期输出：
```
✔ Generated Prisma Client (v6.19.x) to ./node_modules/@prisma/client in XXXms
```

### 第二步：执行数据库迁移（创建表结构）

```bash
npm run db:migrate
```

预期输出：
```
Applied migration 20260531000000_init_sqlite_persistence
Applied migration 20260531001000_add_ai_report_source_metadata
Applied migration 20260531111450_add_assessment_batch
Applied migration 20260531135539_add_item_feedback
```

> 此命令会在 `prisma/` 目录下生成 `dev.db` 文件（SQLite 数据库）。

### 第三步：写入演示种子数据

```bash
npm run db:seed
```

预期输出：
```
Seeding complete.
```

> 此命令向数据库写入：1 个班级、20 名学生、1 名教师、体测记录、AI 报告等演示数据。

### 验证数据库

```bash
npm run db:studio
```

浏览器会自动打开 http://localhost:5555 ，可以在 Prisma Studio 中浏览数据库内容。确认后关闭即可。

## 七、演示账号与使用指南

### 7.1 演示账号一览

### 7.2 学生端体验路径

#### 步骤 1：登录

1. 打开 http://localhost:3000
2. 点击页面右上角 **「我是学生」** 切换到学生登录
3. 在账号下拉框中选择 **S001**（或其他学生编号）
4. 密码会自动填充为 `demo123`
5. 点击 **「进入系统」**

#### 步骤 2：浏览学生首页（Dashboard）

登录后自动进入学生首页，可以看到：
- 问候语 + 综合评分
- BMI 状态卡片
- 最近体测记录摘要
- 快捷入口（体质画像 / AI 指导）

#### 步骤 3：查看体质画像

点击底部导航 **「画像」** 或首页的 **「查看体质画像」**：
- 综合评分 + 本期洞察
- 五维体质雷达图（速度 / 力量 / 耐力 / 柔韧 / 身体形态）
- 历史成绩趋势图
- 优势项目与待提升项目

#### 步骤 4：体验 AI 智能指导

点击底部导航 **「AI指导」**：
- **正式体测分析**：点击「查看报告」查看全维度画像报告（13 个模块）
- **单项深度分析**：点击任意项目卡片，查看专项分析报告（14 个模块）
- **训练情况**：查看近 7 天 / 30 天训练统计
- **历史报告**：底部折叠区域，可回看所有历史报告

#### 步骤 5：记录新的体测数据

1. 点击首页的 **「开始记录」** 大按钮
2. **选择体测批次**：选择一个批次（如"2026春季学期首测"）
3. **选择项目**：勾选要记录的体测项目（如 50米跑、立定跳远）
4. **输入成绩**：使用滚轮选择器输入成绩
5. **填写体感反馈**：RPE 用力程度、恢复速度、肌肉酸痛等
6. **完成保存**：确认后自动保存并返回首页

#### 步骤 6：查看个人中心

点击底部导航 **「我的」**：
- 查看 / 编辑身高体重（自动计算 BMI）
- 查看体测与训练统计
- 退出登录

## 八、接入真实 AI 服务（可选）

项目默认使用内置的 Mock 数据（模拟 AI 分析结果），无需配置 API Key 即可体验全部功能。

如需接入真实 AI 分析服务（DeepSeek），按以下步骤操作：

### 8.1 获取 DeepSeek API Key

1. 访问 https://platform.deepseek.com/
2. 注册并登录
3. 在「API Keys」页面创建一个新的 Key
4. 复制 Key（格式类似 `sk-xxxxxxxxxxxxxxxx`）

### 8.2 配置环境变量

在项目根目录下创建 `.env.local` 文件：

```bash
# Windows PowerShell
New-Item -Path .env.local -ItemType File

# macOS / Linux
touch .env.local
```

用文本编辑器打开 `.env.local`，写入以下内容：

```env
DEEPSEEK_API_KEY=sk-你的API密钥
DATABASE_URL="file:./dev.db"
```

### 8.3 重启开发服务器

```bash
# 先停止当前运行的服务器（Ctrl+C）
# 然后重新启动
npm run dev
```

### 8.4 验证 AI 接入

1. 以学生身份登录
2. 进入「AI 指导」页面
3. 点击「生成报告」
4. 如果报告详情中显示 **「由 DeepSeek AI 生成」** 标签，说明接入成功
5. 如果显示 **「演示模式」** 标签，说明仍使用 Mock 数据，请检查 API Key 配置

> 💡 **提示**：即使配置了 API Key，如果 AI 请求超时（默认 12 秒），系统会自动回退到 Mock 数据，确保演示流程不中断。

## 十、常见问题与排查

### Q1：页面显示"裸 HTML 样式"，没有 CSS 样式

**原因**：Next.js 开发缓存损坏。

**解决方法**：
```bash
# 1. 停止开发服务器（Ctrl+C）
# 2. 删除缓存目录
# Windows PowerShell
Remove-Item -Recurse -Force .next

# macOS / Linux
rm -rf .next

# 3. 重新启动
npm run dev
```

### Q2：`npm run db:seed` 报错 "column does not exist"

**原因**：数据库迁移未完全执行。

**解决方法**：
```bash
# 重置数据库后重新执行
npm run db:reset
npm run db:generate
npm run db:migrate
npm run db:seed
```

### Q3：`npm install` 报错网络超时

**解决方法**：
```bash
# 切换为国内镜像源
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

### Q4：端口 3000 被占用

**现象**：启动时报错 `EADDRINUSE: address already in use :::3000`

**解决方法**：

```bash
# 方法一：查找并关闭占用端口的进程
# Windows PowerShell
Get-NetTCPConnection -LocalPort 3000 | Select-Object OwningProcess
Stop-Process -Id <进程ID> -Force

# macOS / Linux
lsof -i :3000
kill -9 <进程ID>

# 方法二：使用其他端口启动
# 修改 package.json 中 dev 脚本为：
# "dev": "next dev -p 3001"
```

### Q5：`npm run build` 报错

**解决方法**：
```bash
# 先运行类型检查，定位具体错误
npm run typecheck

# 根据错误信息修复后重新构建
npm run build
```

### Q6：Node.js 版本过低

**现象**：启动时报语法错误或不支持的特性。

**解决方法**：升级 Node.js 到 18 或更高版本。推荐使用 nvm 管理 Node.js 版本：

```bash
# 安装 nvm（macOS/Linux）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 安装并使用 Node.js 20
nvm install 20
nvm use 20
```

### Q7：Prisma Studio 打不开或报错

**解决方法**：
```bash
# 确保数据库已初始化
npm run db:migrate

# 重新打开
npm run db:studio
```

### Q8：AI 报告一直显示"生成中"

**可能原因**：
1. 未配置 DeepSeek API Key → 系统使用 Mock 数据，通常几秒内完成
2. 网络问题导致 API 请求超时 → 系统会在 12 秒后自动回退 Mock 数据
3. 浏览器控制台有报错 → 按 F12 查看 Console 面板的错误信息
